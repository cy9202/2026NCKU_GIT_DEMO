# 2026 NCKU Git Demo

這是一個用來練習 Git 與 GitHub 基本操作的示範專案。

## 專案目的

- 熟悉 `git clone`、`add`、`commit`、`push` 等基本指令
- 練習分支（branch）與合併（merge）
- 了解 GitHub 上的協作流程（Pull Request、Issue）

## 快速開始

```bash
git clone https://github.com/cy9202/2026NCKU_GIT_DEMO.git
cd 2026NCKU_GIT_DEMO
```

## 常用指令速查

| 指令 | 說明 |
| --- | --- |
| `git status` | 查看目前工作區狀態 |
| `git add <檔案>` | 將變更加入暫存區 |
| `git commit -m "訊息"` | 提交變更 |
| `git push` | 推送到遠端儲存庫 |
| `git pull` | 從遠端拉取最新變更 |
| `git checkout -b <分支>` | 建立並切換到新分支 |
